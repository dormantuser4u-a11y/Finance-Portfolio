# GST Compliance & Tax Analysis Dashboard

## Objective
Analyze GST transactions and monitor tax collections using an interactive Excel dashboard.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Cards

## Dashboard Features
- Monthly Sales Trend
- GST Rate Analysis
- State-wise Sales
- Product-wise Sales
- Payment Status
